# C5 External Dataset Evaluation

UAV-VisLoc Example의 Sequence 03을 이용해 기존 Trone-iMatch 파이프라인의 외부 데이터 성능을 평가했다.

- 평가 데이터: 260개 표본
- 모델: LoMa-B128, LoMa-B
- 탐색 방식: 8방향
- 위성 지도: 512×512, 0.25m/px, GPS 중심
- UAV 영상: 중앙 568px 크롭 후 256×256으로 변환
- UAV 영상 GSD: 연속 프레임 14쌍으로 추정한 중앙값 0.1128m/px
- Heading 변환: `theta = (-Phi1 + 6) mod 360`
- 평가 환경: Kaggle Tesla T4

기존 `geometry.py`, `pipeline.py`는 수정하지 않았다. 외부 데이터 변환 및 입력 구성을 통해 기존 파이프라인에 적용했다.

## 2. 실행 명령어

### 데이터 변환

최종 변환 스크립트 경로:

```bash
python scripts/export_external.py --help
```

위 명령은 스크립트의 실제 인자 형식을 확인하기 위한 명령이다.

실험 기록에는 `export_external_v5.py`를 사용한 실행 이력이 있으나, 최종 파일명 `scripts/export_external.py`로 변경된 이후의 전체 실행 인자와 명령행은 현재 확인되지 않았다. 따라서 실제 실행 명령은 해당 Kaggle 노트북의 변환 셀에서 확인한 뒤 아래에 그대로 기록해야 한다.

```bash
# 실제 실행에 사용한 전체 명령을 기록
# python scripts/export_external.py [실제 인자]
```

### 평가

평가는 LoMa-B128과 LoMa-B 각각 8방향으로 수행했다. 실제 평가에 사용한 전체 명령행은 실행 노트북 또는 로그에서 확인해 기록한다.

```bash
# LoMa-B128: 실제 평가 명령 기록
# LoMa-B: 실제 평가 명령 기록
```

**주의:** 위 주석 부분은 실행 명령이 확인되지 않은 상태다. 임의의 인자를 추가해 실제 실행 명령처럼 사용하지 않는다.

## 3. Evaluate 결과

260개 전체 표본 기준이며, 실패 표본은 성공으로 계산하지 않았다.

| Metric | LoMa-B128 | LoMa-B |
|---|---:|---:|
| Found | 251/260 | 257/260 |
| 10m 이내 | 12.3% | 14.6% |
| 20m 이내 | 48.1% | 47.7% |
| 32m 이내 | 80.8% | 82.3% |
| 유효 예측 기준 10m 이내 | 12.7% | 14.8% |
| Unknown (Inlier < 15) | 43 (17%) | 39 (15%) |
| 답한 표본 기준 10m 이내 | 13.8% | 15.8% |
| Heading 중앙값 | -1.6° | -2.0° |
| Heading MAD | 2.9° | 2.7° |
| 180° 뒤집힘 | 1 | 0 |
| Inlier 중앙값 | 114 | 129 |
| 초/샘플 | 1.66 | 2.55 |

### Heading 검증

Heading 변환 규칙 설정에 사용하지 않은 새 표본 38개에서 다음 결과를 확인했다.

| Metric | Result |
|---|---:|
| Heading 오차 중앙값 | -2.6° |
| MAD | 3.0° |
| 15° 이내 비율 | 96% |

무작위 방향의 90° 오차 기준보다 일관되게 작은 오차를 보였다. 다만 GPS 및 지도 좌표계의 절대 정확성까지 독립적으로 검증한 결과는 아니다.

### 모델 간 쌍체 비교

직접 계산한 McNemar exact test 결과이며, `metrics.errors()`의 ±1 clip은 적용하지 않았다.

| 기준 | B128만 성공 | LoMa-B만 성공 | p-value |
|---|---:|---:|---:|
| 10m | 2 | 8 | 0.109 |
| 20m | 8 | 7 | 1.000 |
| 32m | 8 | 12 | 0.503 |

위치 정확도에서 두 모델 사이의 통계적으로 유의한 차이는 확인되지 않았다.

## 4. 결과 해석 및 제한사항

- 위성 지도는 프로젝트 기준인 0.25m/px로 변환했다.
- UAV 영상의 0.1128m/px는 연속 프레임으로 추정한 GSD이며, 카메라 보정으로 검증된 값은 아니다.
- `Inlier < 15`는 Unknown으로 집계했지만 파이프라인 전체의 거절 동작으로 완전히 통합하지는 않았다.
- 인접 프레임이 포함되어 있어 260개 표본이 완전히 독립적이지 않다.
- 정답 위치와 추정 위치의 NCC 차이 및 비행 줄별 위치 편향이 관찰되었다. GPS 또는 지도 georeferencing 오차 가능성이 있으나 원인은 확정되지 않았다.
- `evaluate.py`는 외부 데이터 평가에 사용하지 못해 직접 계산으로 대체했다.
- `scripts/check_labels.py`는 실제 실행 경로와 다르다. 실행 기록에서는 저장소 루트의 `check_labels.py`를 사용했다.

## 6. 결론 한 줄

UAV-VisLoc 260개 표본에서 Heading은 새 표본 기준 15° 이내 96%였고, LoMa-B128의 10m 이내 성공률은 12.3%, 32m 이내 성공률은 80.8%였으나 GPS/georeferencing 오차 가능성으로 절대 위치 정확도 해석에는 주의가 필요하다.
